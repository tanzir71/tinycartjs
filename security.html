SECURITY - SERVER TRUTH

TinyCart Security

TinyCart is a storefront widget, not a payment processor. The browser makes checkout pleasant; the server must decide price, discount, stock, payment status, and persistence.

SAFEGUARDS

Implemented safeguards

The default PHP endpoints are deliberately boring: allowlists, prepared statements, bounded inputs, and logs that avoid leaking internals to customers.

PRICE

server-side price verification

checkout.php recomputes products, coupons, totals, and inventory from server data before storing orders.

HMAC

Signed product data

Optional HMAC signatures with expiry add defense in depth for rendered product buttons.

SQL

Prepared writes

SQLite writes use PDO prepared statements and transaction boundaries for order and inventory changes.

CORS

Exact origins

Checkout, coupon, catalog, admin, and collect endpoints use origin allowlists. Avoid wildcard CORS.

LIMITS

Bounded input

Payload size, shape, rate limits, product option parsing, cart storage, and analytics queues are constrained.

DOM

Text-safe UI

Merchant and customer strings are inserted with safe text APIs or escaped templates, not raw HTML.

Merchant duties CSP Rotation Privacy

Still required from merchants

  • Verify product ids, prices, stock, totals, discounts, and payment status server-side.
  • Protect admin and order-management routes with authentication and CSRF protections.
  • Do not expose HMAC_SECRET, API keys, payment secrets, or database files.
  • Use HTTPS everywhere and collect only the personal data your policy allows.

Content-Security-Policy

Use a Content-Security-Policy that names the checkout and collect hosts exactly.

Content-Security-Policy: default-src 'self'; script-src 'self'; connect-src 'self' https://checkout.example.com https://collect.example.com; img-src 'self' data:; style-src 'self' 'unsafe-inline'; base-uri 'self'; form-action 'self'

API key and HMAC rotation

Add a new key or signing secret, deploy clients that use it, confirm traffic moved, then remove the old value after signatures expire. Keep secrets outside git where possible.

Privacy notes

Checkout stores order details, contact fields you request, item data, page URL, an IP hash, and timestamps. The collect endpoint stores operational events, user agent, origin, IP hash, and timestamps. Publish retention terms and delete or export data under applicable privacy law.
