START

Mark a button, load the script.

Use normal HTML for your product layout. TinyCart reads safe product attributes, stores the cart in localStorage, and can show shopper payment choices such as online payment and COD.

<button
  data-tc-id="tee-001"
  data-tc-name="TinyCart Tee"
  data-tc-price="24.00"
  data-tc-qty="1"
  data-tc-options='{"size":"M","color":"Black"}'>
  Add tee
</button>

<script
  src="tinycart.js"
  data-tc-config='{"cartKey":"store-1","currency":"USD","apiCheckout":"/checkout.php","apiCoupon":"/coupon.php","paymentMethods":["online","cod"],"defaultPaymentMethod":"cod"}'>
</script>
HTML

Product attributes

  • data-tc-id is the required product id. It should exist in your server catalog.
  • data-tc-name is display text. TinyCart inserts it with safe text APIs.
  • data-tc-price is a decimal display price. Checkout must re-check it server-side.
  • data-tc-qty, data-tc-options, and data-tc-stock control defaults, variants, and client-side caps.
  • data-tc-sig and data-tc-exp carry optional HMAC product signatures.
CONFIG

Configuration

Use data-tc-config for JSON-only setup. Use tinycart.init when you need hooks or custom functions.

tinycart.init({
  cartKey: "store-1",
  currency: "USD",
  locale: "en-US",
  apiCheckout: "/checkout.php",
  apiCoupon: "/coupon.php",
  catalogUrl: "/catalog.php",
  analyticsUrl: "/collect.php",
  apiKey: "optional-public-endpoint-key",
  accent: "#1A73E8",
  paymentMethods: ["online", "cod"],
  defaultPaymentMethod: "cod",
  allowedOptionKeys: ["size", "color", "finish"],
  onCheckout: async (payload) => fetch("/checkout.php", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(payload)
  }).then((res) => res.json())
});
FLOW

Shopping cart flows

TinyCart provides the cart UI and secure checkout handoff, not a full commerce back office. These are the operational answers most stores need before going live.

Payment flow

Payment providers are disabled by default. Configure online payment, COD, or manual collection in PHP and mirror the choices in data-tc-config. Online orders can redirect to Stripe or PayPal; COD orders stay in ops with cod_due.

Order records

Validated orders are written to data/orders.sqlite. Payment status starts as pending or COD due, then payment.php or the admin dashboard can mark the order paid.

Fulfilment is manual

TinyCart does not ship packages, print labels, or run warehouse workflows. Use admin.php, CSV exports, order email, or a signed webhook to move each order through fulfilment.

Shipping, tax, refunds

Shipping rates, tax calculation, refunds, returns, subscriptions, and customer-service flows are intentionally bring-your-own. Add them in your backend, payment provider dashboard, or existing operations tool.

Inventory and coupons

catalog.php can hydrate display data, coupon.php can preview discounts, and admin.php can update stock or toggle coupon overrides. Checkout still revalidates all product, price, coupon, total, and stock data.

Notifications and analytics

WEBHOOK_URL receives a signed PII-free order summary for integrations. ORDER_EMAIL_TO sends a simple plaintext order email. collect.php can record optional cart events without customer contact details.

API

Developer API

Cart control

init, add, remove, update, getCart, and clear cover the cart lifecycle.

Checkout and coupons

paymentMethods controls shopper choices, and applyCoupon validates locally, through apiCoupon, or with an onValidateCoupon hook.

Events

Subscribe to cart:updated, cart:opened, cart:checkedout, and cart:applyCoupon.

Utilities

flushQueue retries analytics sends. safeTemplate escapes placeholders for integrations.

SERVER

Server endpoints

checkout.php validates origins, rate limits requests, recomputes totals, reserves inventory, stores the order, supports COD/manual/online payment methods, and can hand off to Stripe or PayPal. Optional endpoints add coupons, catalog hydration, analytics collection, payment webhook handling, and an authenticated ops dashboard for order status, COD collection, stock, coupon overrides, CSV export, and webhook retry.

UI

Theme tokens

TinyCart styles are scoped under .tc-root and can be overridden with CSS variables without forking the library.

.tc-root {
  --tc-accent: #1A73E8;
  --tc-bg: #fff;
  --tc-fg: #080808;
  --tc-line: #e7e7e7;
  --tc-radius: 18px;
  --tc-font: Inter, system-ui, sans-serif;
}
