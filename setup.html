SETUP - SHARED HOSTING

TinyCart Setup

A practical deployment path for Namecheap, cPanel-style shared hosting, and static storefronts that need PHP and SQLite behind a small cart UI.

CHECKLIST

Upload, configure, protect.

The basic install is flat files. The important work is tightening origins, secrets, product truth, and file permissions before real orders arrive.

01

Upload files

Put tinycart.js, checkout.php, optional endpoints, and these HTML docs into public_html/tinycart or your storefront directory.

02

Configure origins

Set ALLOWED_ORIGINS, endpoint-specific origin lists, API keys, product catalog rows, coupons, payment credentials, and webhook secrets.

03

Protect data

Create a private writable data/ directory for SQLite, logs, rate-limit buckets, and queued webhook or analytics records.

Requirements Files Permissions Merchant embed Node hosting

Requirements

  • PHP 8.1 or newer is recommended.
  • pdo_sqlite and json are required. mbstring is recommended.
  • A writable private data/ folder is required for SQLite, logs, rate limits, and queues.

Configure the PHP files

Edit checkout.php first. Keep PRODUCT_CATALOG and COUPONS as server truth. Then configure optional coupon.php, payment.php, catalog.php, admin.php, and collect.php only if your store uses those features.

ALLOWED_ORIGINS = ["https://store.example"]
API_KEYS = ["long-random-public-endpoint-key"]
HMAC_SECRET = "server-only-secret"
PAYMENT_PROVIDER = "stripe" // or "paypal", or blank

Protect data and logs

On many cPanel accounts, 750 for directories and 640 for SQLite/log files is enough. Add a .htaccess file inside data/.

Require all denied

Top-level security headers should include a Content Security Policy with exact connect-src origins. Do not use wildcard CORS for checkout or analytics.

Merchant page embed

<script
  src="/tinycart/tinycart.js"
  data-tc-config='{"cartKey":"store-1","currency":"USD","apiCheckout":"/tinycart/checkout.php","apiCoupon":"/tinycart/coupon.php","catalogUrl":"/tinycart/catalog.php","analyticsUrl":"/tinycart/collect.php"}'>
</script>

Common Node hosting

TinyCart itself is static. On Render, Railway, Fly.io, Vercel, Netlify, or a VPS, serve the client file and implement the same endpoint contract: exact origin checks, max body size, field validation, parameterized SQL, and rate limiting.
