TinyCart

Turn any website into a storefront with one script include, product data attributes, and a PHP checkout endpoint that verifies prices before storing orders.

Read the docs View GitHub 
<script src="tinycart.js" data-tc-config='{"cartKey":"store-1","currency":"USD","apiCheckout":"/checkout.php"}'></script>

Embed, sell, verify.

1. Mark products

Add `data-tc-id`, name, price, quantity, options, stock, and optional HMAC signature to existing buttons.

2. Cart opens anywhere

The script renders a mobile-first floating cart, editable quantities, coupon entry, and checkout form.

3. Server decides

The PHP endpoint checks origin, rate limits, re-prices every item, stores the order, and can hand off to Stripe or PayPal.

Privacy-friendly storefront plumbing for static sites and shared hosting.
