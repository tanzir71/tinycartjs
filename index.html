TinyCart turns any static page into a small shop. Mark up products with data-tc-* attributes, drop in one script, and let a PHP endpoint re-price every order server-side before it’s stored.

Small on purpose.

No framework, no bundler, no account. Everything ships as flat files you can read in an afternoon.

01

Server-verified

Price, name, coupon, and stock are re-checked in checkout.php. The client is UX only.

02

Zero build

One vanilla JS file and two PHP endpoints. Drop them on shared hosting and you’re live.

03

Privacy-friendly

Cart lives in localStorage. Analytics are optional, batched, and PII-free.

04

Signable

Optional HMAC signatures on product data add defense-in-depth against tampering.

Embed, sell, verify.

Three moving parts, each with a single job.

01
Mark products

Add data-tc-id, name, price, quantity, options, stock, and an optional HMAC signature to buttons you already have.

02
Cart opens anywhere

The script renders a mobile-first floating cart with editable quantities, coupon entry, and a checkout form.

03
Server decides

The PHP endpoint checks origin, rate-limits, re-prices every item, stores the order, and can hand off to Stripe or PayPal.
